## ADDED Requirements

### Requirement: A regenerated example is never cached

An example generated by a regeneration request SHALL NOT be written to the cache, whatever the cache holds for its subject. The cache is read to learn which sentence to avoid, and that is its only use there.

#### Scenario: Regeneration leaves the cache as it was

- **WHEN** a regeneration request is answered for a subject the cache holds, or does not hold
- **THEN** the cache holds exactly what it held before the request
